Setup Guide
1
Create Google Sheet
Go to sheets.google.com, create a new sheet named Decor Warehouse. Create two tabs: Items and Racks.
2
Open Apps Script
In your sheet: Extensions → Apps Script. Paste the Code.gs file contents and save.
3
Run Setup Function
In Apps Script, select setupSheets from the function dropdown and click Run. This creates all headers automatically.
4
Deploy as Web App
Deploy → New Deployment → Web App. Execute as: Me. Access: Anyone. Copy the URL.
5
Connect Here
Paste the URL above, click Test then Save & Connect. Done!
